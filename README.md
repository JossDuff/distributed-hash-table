# distributed-hash-table
Distributed replicated hash table with crash-stop tolerance.  Assignment 3 for Lehigh University's distributed systems Spring 2026 class, based on [https://github.com/JossDuff/dht](https://github.com/JossDuff/drht).

# Environment
This repo is run on Lehigh's internal network, sunlab.  Sunlab supports rustc 1.75.0
